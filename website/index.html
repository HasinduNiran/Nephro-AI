Platform Overview

Four Integrated AI Components

Each component addresses a distinct clinical challenge in CKD management, unified in the Nephro-AI React Native mobile application.

🤖

Bilingual CKD Chatbot (NephroBot)

Sandwich RAG Architecture enabling English and Sinhala/Singlish medical Q&A grounded in 148 KDIGO/NKF clinical guideline documents. Features TinyBERT cross-encoder re-ranking and parallel asyncio TTS streaming.

  • 93.7% Singlish NLU accuracy
  • 96.8% Clinical precision
  • 820 ms first-audio latency
  • 0 ms emergency alert (pre-cached)
📊

Early CKD Risk Prediction

Stacking ensemble of fine-tuned XGBoost and Random Forest (meta-learner: Logistic Regression) using Google Health Connect smartwatch BP data, HbA1c, and 20-feature engineering framework with SHAP explainability.

  • 98.83% accuracy (AUC = 0.997)
  • 5 minimally invasive inputs
  • Longitudinal y=mx+c trend analysis
  • SHAP plain-language explanations
🍽️

Automated Meal Plate Analysis

Fixed-geometry digital overlay resolves the Dimensionality Gap (2D→3D), enabling pixel-precise renal nutrient budgeting. Fine-tuned YOLOv11m on 4,200 Sri Lankan food images across 32 classes including Mallum, Pol Sambol, Dhal curry.

  • 87.0% mAP@0.5 on Sri Lankan foods
  • SAM: 4.4% area overestimation vs 22.7%
  • KDOQI-aligned Nutrient Wallet
  • 100% safety logic adherence
📈

CKD Progression Forecasting

Multimodal LSTM integrating U-Net kidney ultrasound segmentation (kidney length) with Tesseract OCR-extracted lab biomarkers (eGFR, creatinine) for both next-visit and 6-month CKD stage progression prediction.

  • 97.63% U-Net segmentation accuracy
  • 78% next-visit prediction accuracy
  • 74% 6-month forecasting accuracy
  • MIMIC-IV clinical dataset training

Research Domain

Domain Overview

Comprehensive research background, identified gaps, and methodological contributions of the Nephro-AI project.

📚

RAG in Clinical NLP

Lewis et al. (NeurIPS 2020) formalised RAG as a mechanism grounding generative LLMs in retrieved documents to reduce hallucination. Medical RAG systems (MedRAG, BioRAG) demonstrate strong factuality on English queries but have not addressed low-resource code-mixed input or the semantic collision problem in bi-encoder retrieval for antonymous clinical terms (e.g., "high BP" vs "low BP").

🌐

Low-Resource & Code-Mixed NLP

LaBSE (Feng et al., ACL 2022) generates language-agnostic sentence embeddings across 109 languages enabling zero-shot cross-lingual transfer. However, its application to Romanised Sinhala (Singlish) with non-standard orthography and productive suffix morphology had not been evaluated prior to this work.

🍽️

Image-Based Dietary Assessment

Deep learning approaches using CNNs and transformers achieve strong classification on Western food benchmarks but fail on Sri Lankan staples with textural ambiguity. SAM (Kirillov et al., ICCV 2023) enables zero-shot food segmentation. No prior system combined image-based portion estimation with CKD-stage-specific renal nutrient thresholds for South Asian populations.

💓

Wearable BP & ML Risk Models

Consumer smartwatches achieve within-5 mmHg agreement with auscultatory measurements. Ensemble ML methods (stacking) consistently outperform single classifiers on CKD classification tasks. SHAP TreeExplainer provides clinically interpretable feature attributions. Prior work used single BP readings; multi-day wearable averages were not integrated.

🧬

Multimodal CKD Progression

LSTM networks effectively capture temporal patterns in sequential clinical records. U-Net architectures segment kidney regions from ultrasound images, enabling kidney length extraction as a structural biomarker. Existing studies focus on either clinical data OR imaging data — not a unified multimodal framework with temporal modelling.

🔊

Multilingual TTS & Voice Interfaces

Sinhala TTS remains underexplored. Google Cloud TTS supports Sinhala (si-LK) but fails on embedded Latin characters. Whisper-large-v3 (Radford et al., ICML 2023) achieves competitive WER across languages with domain adaptation via context prompting. Prior mobile health TTS deployments used synchronous paradigms with 4–10 s latency.

🎯 Gap 1 — No CKD-Specific Sinhala Conversational AI

No existing system provides a Sinhala-language conversational interface for CKD patient education grounded in current clinical guidelines (KDIGO 2024). Generic Sinhala health chatbots lack the domain-specific entity ontology (171 CKD terms), clinical guideline RAG, and negation detection required for safe medical advice.

🎯 Gap 2 — Singlish Medical NLP Unaddressed

Singlish — phonetic Sinhala in Latin script — is the dominant input modality on mobile devices yet is absent from published multilingual NLP benchmarks. No prior work addresses Singlish medical entity extraction with agglutination-aware suffix stripping, fuzzy Levenshtein matching, and cross-lingual zero-shot intent classification simultaneously.

🎯 Gap 3 — Bilingual RAG Architecture

Standard RAG systems assume monolingual operation. Retrieving from English medical documents in response to Sinhala queries requires a translation bridge not provided by existing RAG frameworks. The Sandwich Translation Architecture developed here is a novel solution to this fundamental cross-lingual retrieval problem.

🎯 Gap 4 — Sri Lankan Dietary Assessment

No prior automated dietary system targets Sri Lankan cuisine with stage-dynamic renal nutrient thresholds (Sodium, Potassium, Phosphorus, Protein) aligned to KDOQI guidelines for CKD Stages 1–5. Existing apps (MyFitnessPal, NutriKidney) omit renal micronutrients and use static thresholds.

🎯 Gap 5 — Multimodal CKD Progression

Most CKD progression studies use either clinical data or imaging data — not a unified framework. The combination of U-Net ultrasound kidney length features with LSTM temporal modelling of OCR-extracted lab biomarkers from a real-world dataset (MIMIC-IV) had not been demonstrated prior to this work.

Central Research Problem

How can a comprehensive AI-driven mobile health platform be designed and implemented to provide Chronic Kidney Disease patients in Sri Lanka with: (1) accurate, clinically grounded bilingual medical information through a conversational AI that handles English, Sinhala Unicode, and informal Singlish input; (2) early risk identification from passively collected smartwatch biometrics; (3) automated renal dietary monitoring from smartphone images of Sri Lankan meals; and (4) longitudinal CKD progression forecasting from multimodal clinical and ultrasound data — all integrated within a single mobile application accessible to patients with limited digital literacy?

Sub-Problem 1

How can biomedical NER, negation detection, and cross-lingual intent classification be applied to CKD-domain queries in both English and Romanised Sinhala (Singlish) in a real-time API environment?

Sub-Problem 2

How can a large corpus of English CKD clinical guidelines be made accessible to Sinhala-speaking patients through a bilingual RAG pipeline that preserves clinical accuracy?

Sub-Problem 3

How can 3D volumetric food mass be reliably estimated from a 2D smartphone image to enable milligram-level renal nutrient tracking without specialised hardware?

Sub-Problem 4

How can structural kidney features from ultrasound and functional biomarkers from lab reports be fused with a temporal model to predict CKD stage progression over clinically relevant time horizons?

Main Objective

To design, implement, and evaluate a comprehensive AI-driven mobile health platform for Chronic Kidney Disease management that provides bilingual patient education, early risk prediction, automated dietary monitoring, and progression forecasting within a unified React Native application.

NephroBot — Sandwich RAG

  • Singlish → English via 4-stage Hybrid NLU (regex suffix strip → Rapidfuzz Levenshtein ≥85% → LaBSE zero-shot)
  • ChromaDB bi-encoder retrieval (k=15) + TinyBERT cross-encoder filtering (σ threshold τ=0.01)
  • Live MongoDB patient biometrics injected into Gemini 2.5 Flash context
  • Code-Mixed Sinhala NLG with Multi-Register Glossary + parallel asyncio TTS streaming (600-char chunks)
  • MD5 cache with timestamp invalidation for fresh biometric-aware responses

Risk Prediction — Stacking Ensemble

  • 5 inputs: age, gender, 7-day avg SBP/DBP (Health Connect), HbA1c
  • 20-feature engineering (pairwise products, MAP, clinical JNC-7 bins)
  • RandomizedSearchCV hyperparameter tuning (20 iter, 3-fold CV)
  • Stacking: XGBoost + Random Forest → Logistic Regression meta-learner
  • SHAP TreeExplainer + linear regression trend analysis (y=mx+c)

Meal Analysis — 2D→3D Pipeline

  • Fixed-geometry overlay: d=30cm, 1 pixel = 0.217mm constant
  • YOLOv11m fine-tuned on 4,200 Sri Lankan images (32 classes, 100 epochs, NVIDIA A100)
  • SAM ViT-B binary mask for pixel-precise fill ratio vs bounding box
  • Mass = FR × V × H × D × ρ (5-parameter morphology-aware formula)
  • Nutrient Wallet: KDOQI-aligned Na/K/P/Protein thresholds for all 5 CKD stages

CKD Progression — Multimodal LSTM

  • U-Net segmentation: kidney length = D_pixel × R (pixel→cm calibration)
  • Tesseract OCR extraction of eGFR and serum creatinine from lab reports
  • MIMIC-IV for clinical temporal data; Kaggle US Simulation for ultrasound
  • LSTM with MAX_SEQ_LEN=10 visits, SoftMax output over CKD stages
  • Multi-task: next-visit prediction + 6-month forecasting
